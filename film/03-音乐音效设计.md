## 零 · 四条硬约束

| 约束 | 落实 |
|---|---|
| 每一个音符、音效都由代码合成 | 全片**不引用任何音频文件**。弦体、房间噪声底、混响、合唱垫全部程序生成。唯一可选外部资源是 SoundFont，且有纯合成替代路径（§6.5） |

## 一 · 材料：一个泛音列

### 1.1 主音与八个分量

`f₁ = 110 Hz`（A2），`fₙ = n·f₁`。各分量的振幅取自**拨弦点在 0.35L 处**的三角初形：

```
aₙ ∝ sin(nπ · 0.35) / n²
```

| n | 频率 Hz | `sin(0.35nπ)/n²` | 归一化（Σ\|aₙ\|=1） | 在片中 |
|---|---|---|---|---|
| 1 | 110 | +0.8910 | 0.7183 | 基频。**名字** |
| 2 | 220 | +0.2023 | 0.1631 | 八度。厚度 |
| 3 | 330 | −0.0174 | 0.0140 | 五度。与 E3 的第一条航线 |
| 4 | 440 | −0.0594 | 0.0479 | 双八度。与 D3 的航线 |
| 5 | 550 | −0.0283 | 0.0228 | 大三度 |
| 6 | 660 | +0.0126 | 0.0102 | 与 E3、C3 的航线 |
| 7 | 770 | +0.0202 | 0.0163 | **被拿走的那一根**（S10） |
| 8 | 880 | +0.0092 | 0.0074 | 最高的一根。真空段（S20）单独响的就是它 |

> **为什么第七根是它**：`a₇/Σ|aₙ| ≈ 1.6%`。拿走它，波形变化约 1.6%，**人耳在混响里听不出**。这不是为了效果挑的，是算出来的。
>
> **归一化口径**：上表按 `Σ|aₙ|=1` 归一化，便于混音。画面上齿高按最大位移归一化，故齿高比例与上表略有出入——两者必须由同一份 `partials_table.json` 导出，不许各算一套。

### 1.2 三个动作

| 动作 | 做法 | 出现 |
|---|---|---|
| **建立** | 从 n=1 起逐个加入，每个 120 ms 起振，相位锁定 | S03–S04、S27–S31 |
| **拆解** | 从 n=8 起逐个移除，系数归零（不是淡出），同一帧生效 | S10、S22–S24 |
| **还原** | 按存下的 `aₙ` 从低次到高次放回 | S27–S31 |

**没有四音动机。** 这个泛音列自己就是动机：它的每一次加减，都是一个可听的、可算的和声事件。

### 1.3 纯律与航线

第四乐章的其他岛各有基频，全部取**纯律**比值（相对 A2）：

| 岛 | 基频 Hz | 比值 | 与 A2 精确共有的泛音 |
|---|---|---|---|
| A2 | 110 | 1:1 | 全部 |
| E3 | 165 | 3:2 | 330、660 |
| C3 | 132 | 6:5 | 660 |
| D3 | 146.67 | 4:3 | 440、880 |
| G3 | 176 | 8:5 | 880 |
| B3 | 198 | 9:5 | 无（在八个泛音内不连） |

**航线不是画上去的**：两条泛音列里没有一个精确相等的频率，就没有线。B3 在片中是孤岛——海就是"还没有被听见的部分"。

## 四 · 两个贯穿声音

### 4.1 弦体

弦不是一条数学线，它有身体：张力、木头、空气。

- **张力**：55 Hz 与 82.5 Hz 的极低共振（弦与支点的结构噪声），只在起振与停止时出现。
- **木头**：150–400 Hz 的窄带共振，随振幅变化；`a₁` 越大越明显。
- **空气**：2–6 kHz 的极轻摩擦噪声，只在起振的 120 ms 内出现。

**原则**：弦体永远不盖过泛音。它是"这东西有重量"的证据，不是音色。

### 4.2 房间噪声底

这是全片最重要的声音设计。

- 一层宽频、无音调、极低的底噪（-60 dBFS 起），**在第一乐章被八个泛音完全掩蔽**。
- 每拿走一根泛音，底噪的相对电平上升 **1.5 dB**。
- 第二乐章末尾（只剩基频），它是唯一还在"铺满"的东西。
- 还原时，它随分量回来而重新被掩蔽——**还原把房间重新盖住了**。
- 第五乐章末 8 秒，它是真空里唯一剩下的东西。

> **它不是"环境声"，它是"总结之后露出来的部分"。** 混音时不许把它当氛围垫，它的电平必须与泛音数量严格联动。

### 4.3 时间尺度的咔哒

每 2 秒一次，极轻（-46 dBFS），像仪器的心跳。只在 S08 与 S49–S50 出现。它提醒观众：画面是被放慢的。第五乐章停止尺度时，咔哒同时停止。

## 五 · 关键音效

### 5.1 加法合成：画面与声音同源

```js
// 同一组 aₙ，同一组相位；画面取 t 时刻的空间曲线，音频取同一条曲线的时域采样
sample(t) = Σ aₙ · sin(2π · n · f₁ · t + φₙ)
curve(x, t) = Σ aₙ · sin(nπx/L) · cos(2π · n · f₁ · t + φₙ)
```

- 相位 `φₙ` 全部为 0（拨弦初形是实函数，相位为零）。
- 起振包络 120 ms，释放按弦的阻尼（`τₙ ∝ 1/n`）。
- **验收**：对渲染出的音频做 FFT，八个峰的位置与高度必须与画面梳齿一致（容差 0.5 dB / 1 Hz）。

### 5.2 拿走一根泛音：为什么听不出

`a₇` 只占 `Σ|aₙ|` 的 1.6%。移除它是**系数归零**，不是淡出：

- 移除必须发生在**一个采样点内**（不是 10 ms 的 ramp），否则会听到"咔"。
- 但"咔"也不许出现——解决办法是移除时刻落在波形过零点附近（相位 0），并做 2 ms 的去 click 窗。
- **不许**为了"让观众听出来"而提升 `a₇`。听不出来是设计：字幕卡说的就是这件事。

### 5.3 残差归零的那一下

S31，2:24。八根齿全部回来，残差跳到 0.000。

- 声音：八个分量在同一采样点全部就位，**没有渐入**。
- 加一击极轻的木质"合上"（80 Hz + 1.2 kHz，τ=90 ms，-34 dBFS），不是打击乐，是"合上一本书"。
- 这一下是全片唯一的"爽点"，**不许加混响尾巴**——它必须干。

### 5.4 金线（记录）

S26。金线是记录，不是声音。声音上只有一个极轻的玻璃质高频（2.8 kHz，τ=1.8 s，-40 dBFS），像一根玻璃丝被轻轻碰了一下。

### 5.5 大陆：航线 = 共有泛音

- 每座岛的基频按纯律（§1.3）。
- 航线出现时，两端的岛各响一次自己的那个共有泛音（例如 A2 与 E3 共享 330 Hz：两座岛同时响 330 Hz，但音色不同）。
- **两条泛音列没有精确相等的频率，就没有声音，也没有线。**

### 5.6 Φ

一个暖色光点，声音标识是"键盘节奏"：每 180–260 ms 一次极轻的木质"嗒"，音高在 1.2–1.6 kHz 之间随机。它不旋律、不歌唱，只是"在动"。

Φ 碰节点时，只放回**一根**泛音，然后停在一个不解决的音上（`a₅`，550 Hz，悬置）。

### 5.7 两次静默

- **第一静（A20，88 s，-62 dB）**：只剩 880 Hz。三秒。它必须比周围**低 30 dB 以上**，否则不成立。
- **第二静（A54，255–263 s，-52 dB）**：末 8 秒无音乐、无音效、无字幕。只有极轻的空间底噪。**这 8 秒必须真的空**——任何为了"保险"加的低频垫都会毁掉它。

## 六 · 合成与母带

### 6.1 工具链

| 环节 | 工具 | 备注 |
|---|---|---|
| 合成 | Node + Web Audio OfflineAudioContext（或 Python + numpy） | 一次性渲染 13.2 M 样本 |
| 混响 | 代码生成 IR，卷积 | 见 6.2 |
| 母带 | ffmpeg + loudnorm（两遍） | 见 6.4 |
| 校验 | FFT 比对 + LUFS/True Peak | 见 6.6 |

### 6.2 混响

- **三种空间**：弦边（0.9 s）、图内（2.4 s）、大陆（4.2 s）。
- IR 由指数衰减噪声 + 早期反射生成，固定种子。
- **两次突变**：S34（0.9 → 2.4 s，180 ms 过渡）、S51（2.4 → 0.6 s，180 ms 过渡）。突变是电影语言，不是自然混响。

### 6.3 5.1 布局

| 声源 | L | R | C | LFE | Ls | Rs |
|---|---|---|---|---|---|---|
| 主音（弦） | 0.7 | 0.7 | 0.3 | 0.1 | 0 | 0 |
| 880 Hz 真空 | 0 | 0 | 1.0 | 0 | 0 | 0 |
| 房间底噪 | 0.6 | 0.6 | 0 | 0 | 0.5 | 0.5 |
| 大陆 | 0.5 | 0.5 | 0.2 | 0.3 | 0.6 | 0.6 |
| Φ | 0.2 | 0.8 | 0 | 0 | 0 | 0 |

LFE 只在 A35（尺度崩塌）与 A37（大陆脉动）有内容，且 ≤ -20 dBFS。

### 6.4 母带链

1. 总线压缩（2:1，阈值 -20 dBFS，attack 30 ms，release 250 ms）——只在 A35–A41 启用。
2. 三段 EQ：60 Hz 以下高通（除 LFE）、2–4 kHz 轻微去齿音、12 kHz 以上轻微衰减。
3. 限幅：ceiling -1.2 dBTP。
4. loudnorm 两遍：目标 -18 LUFS，TP -1.5 dBTP，LRA 7。

### 6.5 外部资源

不使用 SoundFont、不使用采样。若未来需要更真实的弦体，可用物理建模（Karplus-Strong）替代，但**主音的八个分量必须仍是加法合成**——否则声音与画面不再同源。

### 6.6 确定性与音画同步

- 单一离线渲染，固定种子。
- 音画同步以**采样点**为准：第 f 帧 = 样本 `f × 2000`。
- 逐条 cue 的 `start_frame × 2000` 必须等于音频文件的切点。
- 验收脚本：`verify_audio_sync.mjs`（待写）——比对每条 cue 的起止样本与 JSON。

## 七 · 失败模式清单

| # | 失败 | 症状 | 处置 |
|---|---|---|---|
| 1 | 泛音不是整数倍 | 合成长度对不上，声音"脏" | 频率表由 `partials_table.json` 唯一导出 |
| 2 | 用了平均律 | 航线两端的频率差几赫兹 | 全片纯律；航线判据 `|f_a − f_b| < 0.01 Hz` |
| 3 | 移除泛音做了淡出 | 听到"渐弱"，不是"消失" | 系数归零 + 过零点 + 2 ms 去 click |
| 4 | 为了听得出而提升 a₇ | 观众听出"少了一个"，字幕卡变成废话 | 严格按 `sin(0.35nπ)/n²` |
| 5 | 房间底噪当氛围垫 | 它不再随泛音数量变化，第二乐章失效 | 底噪电平 = f(泛音数)，写入代码 |
| 6 | 残差归零加了渐入 | 爽点变成"恢复原状" | 同一采样点全部就位 |
| 7 | 8 秒静默加了低频垫 | "最自信的 8 秒"变成"最没底的 8 秒" | 真空，包括 LFE |
| 8 | 母带把 -18 LUFS 做成 -14 | 动态被压平，全片最响与最静只差 20 dB | 两遍 loudnorm，LRA 7 |
| 9 | 时间伸缩也用在音频上 | 音高变了，全片论据垮 | 伸缩只在画面；音频实时 |
| 10 | Φ 的键盘声有旋律 | 变成角色，违反"无人" | 音高随机，不构成音阶 |
| 11 | 大陆全奏提前 | 2:45 之前出现全奏，第四乐章失效 | 检查 0–165 s 的 cue，任何全奏都删 |
| 12 | 混响突变做成渐变 | 两次穿入失去电影语言 | 180 ms 过渡，不是 2 s |
