# 《一个问题，长成一片大陆》
## *A Question Grows into a Continent*
### PhyMathia · 项目介绍片

> 无对白动画短片 · 正片 4 分 30 秒 + 尾板 5 秒 · 2.39:1（3840×1608，精确 2.388:1）· 24 fps · 5.1
> 每一帧画面、每一个音符，皆由代码生成
> **全片只出现 PhyMathia，不出现任何其他署名**

---

## 三十秒读懂这部片子

**一句话**：你在一个空白的画布上问了一个问题。它用两套语言回答你。那个回答变成一张卡片；卡片长出邻居；邻居连成一片大陆。

**它介绍的是产品本身**：不是功能清单，是 PhyMathia 被使用时的样子。全片是一次真实使用的重演——输入、双域回答、卡片、追问、图谱、大陆、记忆、Φ。

**片子里唯一的那道题**：

> 为什么一个音，听起来是一个音？

左边是物理（一根弦的许多种振动），右边是数学（那些振动是 `sin(nπx/L)` 的和）。**两边被同一组数字锁死**——这就是产品的回答方式。

## 五乐章结构

| 乐章 | 时间 | 时长 | 动作 |
|---|---|---|---|
| **I 问** | 0:00–1:05 | 65" | 空白画布 → 输入一个问题 → 回答开始展开 |
| **II 答** | 1:05–1:45 | 40" | 两个面锁上：物理直觉 / 数学本质 |
| **III 卡** | 1:45–2:45 | 60" | 卡片、邻居、星座、苏格拉底追问 |
| **IV 大陆** | 2:45–3:50 | 65" | 缩远成大陆；金边记忆；Φ 连一半 |
| **V 回来** | 3:50–4:30 | 40" | 回到最初那个问题；答案还在 |
| 尾板 | 4:30–4:35 | 5" | PhyMathia / MADE WITH CODE |

**最关键的一次交易**：前 165 秒不出现任何"大陆"级别的尺度，也不出现一次全奏。攒起来，换第四乐章的 65 秒。

## 下一步：顺序不能颠倒

1. **你先读剧本**，确认三件事：主角是"你"和画布、示例问题是"一个音"、全片只有 PhyMathia。
2. **重铺 02 / 03 / 05 / 08**——55 镜、Cue Sheet、时间线、报名材料。
3. **技术验证**：真 GPU（`UNMASKED_RENDERER_WEBGL`）→ 同帧三次 hash 闸门 → 五个 P0 镜头（输入 / 翻面 / 点卡连边 / Φ 连一半 / 穿进卡片）。
4. 三者都过了，再启动全面生产。

## 两个需要你拍板的决定

### 1. 片长与赛道

近 8 届戛纳金棕榈短片没有一部低于 9 分钟。4:30 对标的不是戛纳短片竞赛的主赛道。**这一版是产品片，建议走 A：保持 4:30，投友好影展 / 官网 / 创投；戛纳另做 9–12 分钟版。**

### 2. 示例问题

片子里的题是"为什么一个音，听起来是一个音？"。它把双域解释演得最干净，但**可以换成任何一道同时有物理直觉和数学结构的题**——结构不动，只换内容。
