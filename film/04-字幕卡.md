## 一 · 一条原则：先让画面说，说不出来才用字

这部片子是产品片，最容易犯的错是**用字解释功能**。所以规矩比上一版更狠：

**凡是产品动作能演的，一个字都不给。**

- "支持双域解释" → 不给。给卡片翻开，左弦右数，同一个数同时亮。
- "支持知识图谱" → 不给。给点一张灰卡，它变实，连一条线。
- "它会记得你" → 不给。给金边卡片在镜头经过时自己亮一下。
- "Φ 不替你思考" → 不给。给 Φ 连一半，停住，退开。

**全片只有四句话必须给字。** 它们都是动作说不出来的：

1. 一个领域的判断（物理给直觉，数学给结构）
2. 一个知觉事实（你听不出少了哪一个）
3. 一个主张（一个答案，不该只是一行字）
4. 一个承诺（你问过的问题，还在这里）

其余全部交给画面和声音。

## 二 · 字体与排版

| 项 | 规范 |
|---|---|
| 中文正文字体 | **Noto Serif SC / 思源宋体**（SIL OFL）— 衬线、克制、无装饰 |
| 英文正文字体 | **EB Garamond Italic**（SIL OFL）— 斜体，与中文宋体气质相配 |
| 书法字体 | **霞鹜文楷 / LXGW WenKai**（SIL OFL）— 仅用于对联与主标题 |
| UI 字体 | **Inter（或产品顶栏同款无衬线）** — 界面字标、卡片标题、工具栏 |
| 数学记号 | **Latin Modern Math / STIX Two Math**（SIL OFL）— 频率、周期括号、残差 |
| 中文主卡字号 | 画面高度 **4.5%**（1608px → 约 72px） |
| 英文副卡字号 | 中文的 **40%**（约 29px），颜色比中文暗 **25%** |
| 位置 | 中下部；左右安全边各 **8%**，下安全边 **12%** |
| 显影方式 | **不是淡入**。逐字显影：每字间隔 120ms，单字在 400ms 内由 0 → 全亮 |
| 退场方式 | 统一用 600ms 溶解，不用位移 |

**四条禁用**：

1. **禁止字幕卡与音乐重音同步。** 卡出现时音乐必须正在平稳进行。
2. **禁止给字幕卡配打字机音效。** 键盘声只属于画布里的输入（IN01），不属于卡。
3. **禁止出现任何产品界面截图式的构图。** 卡片可以入画，但摄影机永远不是在"演示功能"。
4. **禁止在卡上写功能名。** 没有"双域解释""知识图谱""智能体"这些词出现在画面上。

## 四 · 关键卡的位置逻辑

**T01 落在中缝上。** 它是全片唯一一张横跨卡片两个面的字幕卡——因为它说的就是这两个面的事。字必须压在缝上，不能偏左或偏右。

**T02 只在 3.5 秒。** 它是一句事后确认，不是提示。卡出现时第七条正弦已经暗下去、声音已经过去了。**卡不许提前。**

**T03 落在星座上方，不许压住任何一张卡。** 它说的是"一个答案"和"一行字"的关系；画面里刚好有五张卡连成一个结构。

**T04 落在最初那张卡下方。** 它是全片最后一句人话，之后只有 8 秒静默和主标题。**它必须轻，不能像广告语。**

**T05 的排版**：PhyMathia 用无衬线（与产品顶栏一致），对联用书法体，两者大小差距必须悬殊（对联字号约为 PhyMathia 的 45%）——让"名字"是名字，"主张"是主张。

## 五 · 英文翻译校核

1. **「物理给出直觉。数学给出结构。」→ "Physics gives intuition. Mathematics gives structure."**
   两个短句，中间一个句号。不要 "Physics provides intuition, while mathematics provides structure"——那太像论文。

2. **「你听不出少了哪一个。」→ "You cannot hear which one is missing."**
   不用 "you can't tell the difference"——太技术。"which one" 把注意力钉在具体的某一个上。

3. **「一个答案，不该只是一行字。」→ "An answer should not be only a line of text."**
   不用 "just a line"——"just" 太轻，"only" 才是"只剩下"。

4. **「你问过的问题，还在这里。」→ "The question you asked is still here."**
   用 "still here"，不用 "saved"。"saved" 是功能，"here" 是地方。

**「数学穷天地之理」→ "Mathematics fathoms the reason of heaven and earth."**（沿用）："穷"取"穷尽、探究到底"义，用 *fathom*（测深、彻底理解）而非 *exhaust*。*fathom* 同时有"测量深度"的物理动作感，与 "draws the shape"（绘形）形成对仗。
