# 本次可用的讲法（可选，不适用就忽略本段）

适用：用户要弄清一个装置「由什么组成、各自干什么、怎么连起来工作」。不适用：纯公式
推导、纯概念辨析、只问一个数值。

若采用，按这四段推进，每段两到四句，不要写成产品说明书：

1. 整体：先一句话说清它替人干的那件事，再点出最外层的三到五个大件。
2. 分层：把大件按「外壳 → 内腔 → 运动件 → 传动件 → 回转件」切开，说明为什么这样分层——
   分层依据是「谁把运动/信号传给谁」，不是外形相似。
3. 零件：只挑跨层咬合的两三处细讲：谁在推谁、力或信号怎么传过去、哪里最容易坏。
4. 合回：按一个完整工作循环把各层串一遍，最后指出一个反直觉的细节（例如某个零件
   其实一直在动，或者一直不动）。

红线：不写「如图所示」这类空指代；没有依据的尺寸、压力、温度不写具体值；每一段都要
落到用户能指认的零件名上，讲完能让他在脑子里把整台机器转起来。
