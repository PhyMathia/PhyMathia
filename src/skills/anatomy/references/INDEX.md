# 参考目录（供模型挑读）

一行一份，格式：`文件名 — 一句话说明`。这个文件是给模型看的目录，**不进提示词的全文**：
只把这几行发过去，让它挑最多 2 份，再去读被挑中的那份。

排序按「本项目最常用」在前。标了「本项目不适用」的排在后面，模型会跳过它们。

craft.md — 部件词典、五档明暗、画家顺序、相机与构图、反模式清单
motion.md — 缓动与真弹簧、无人时巡演、指针与键盘映射、无障碍与减弱动效
verify.md — 验收清单：线头断了、穿模、深度序、材质读不出、贴图骤停
walkthrough.md — 一个完整例子（测试台）从构思到成图的顺序，适合照抄结构
kit.md — 上游生成器 API 清单（本项目拿不到脚本，只在需要精确几何算法时查思路）
3d.md — 真三维回转件模式（本项目产物是纯 SVG，不适用）
webgl.md — WebGL 着色器（本项目禁止外部库、不用 WebGL，不适用）
print.md — A4 打印与海报（本项目不产出打印件，不适用）
publish.md — 发布到上游社区画廊（不适用）
react.md — React / Next.js 版本（本项目产物是单文件 HTML，不适用）
