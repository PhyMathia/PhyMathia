功能演示

网络画布

新会话从一个中心问题节点开始，提问后答案、物理、数学、图谱、可视化和延伸思考会从中心向外生长。拖动气泡、滚轮缩放、右下角拉尺寸、最小化和删除都在这里演示。

中心连线节点从中心向四周延伸，拖到任意位置后连线仍指向气泡中心。
气泡操作最小化只保留标题，删除移除整条分支，右下角可调整宽高。
分支探索追问、没看懂、进阶学习都会连接到来源气泡，形成树状网络。
内容滚动气泡内内容过长时使用细滚动条，滚轮在内容区滚动不会缩放画布。

双域回答卡片

完整回答会拆成摘要、物理视角、数学视角、知识图谱、交互可视化和延伸思考。模块支持折叠、追问和没看懂。

物理视角
回复力决定周期。弹簧把物体拉离平衡位置后，回复力始终指向平衡位置，且大小与位移成正比。这个“指向平衡位置 + 线性回复”的组合，是简谐运动能稳定重复的关键。
数学视角
二阶线性常微分方程的解给出位移随时间的变化：
x(t) = A cos(ωt + φ)
ω = √(k / m), T = 2π / ω
知识图谱 
回复力 → 位移 → 速度 → 加速度
     ↓         ↓        ↓
  势能变化    动能变化    能量守恒
延伸思考
基础：如果没有摩擦和空气阻力，振动会不会永远持续？
进阶：弹簧并联后，等效劲度系数为什么变大？
拓展：量子力学中的谐振子为什么如此重要？
公式标注AI 输出用 <formula> 包裹 LaTeX，前端统一转为 KaTeX 渲染。
摘要提取回答末尾的 <summary> 被收集为知识摘要，不显示在卡片正文中。
模块动作每个模块都可以从对应气泡继续追问，不会错误地变成一条孤立主线。

知识总览

对话回答后自动提取知识点和公式，也可以手动收藏。支持分类、来源、搜索、展开详情、跳转原对话和删除。

添加自定义模型

支持 DeepSeek、OpenAI、llama.cpp 本地服务和任意 OpenAI 兼容地址。

存储策略

真实应用会同时写入 localStorage 和服务端 JSON，并通过 15 秒同步与关闭前 flush 保证不丢数据。

本地优先 · 服务端合并
清除当前会话会同时清理该会话消息、知识点和公式；删除会话也保持对称清理。

会话管理

多会话支持新建、切换、重命名、图标切换和删除。每个会话拥有独立的聊天记录、网络布局、知识点和公式来源。

独立布局每个会话保存自己的节点位置、尺寸和折叠状态。
自动标题第一条用户问题会作为会话标题，也可以手动重命名。
图标管理力学、电磁、量子、微积分等几十种图标可快速切换。
跨端同步服务端可恢复 localStorage 中未上传的会话和消息。

交互式可视化

AI 生成完整 HTML 后，前端用 sandbox iframe 展示，支持全屏、复制源码、新标签页打开和主题同步。

拖动参数实时更新波形，模拟 AI 可视化中的可调参数交互。
安全隔离HTML 放在 sandbox iframe 中运行，并清理 parent/top/window.open 等危险引用。
主题桥接父页面切换主题时向 iframe 广播，iframe 可走原生主题或滤镜兜底。
工具链可视化卡片提供没看懂、全屏、复制源码、新标签页打开。
非完整片段过短的 HTML 代码块不会被误判为可视化页面，保留为普通代码。
