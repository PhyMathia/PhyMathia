M0 spike：可视化校验约定链路验证装置

复刻 render.js buildVizCard 的真实注入机制：_sanitizeVizHtml 清洗 → </head> 前注入校验桥 → <iframe sandbox="allow-scripts"> + srcdoc → parent 侧按 event.source 匹配卡片。 校验桥为 M1 _VIZ_CHECK_BRIDGE 的原型：轮询探测 window.__PHYMATHIA_VIZ__（200ms × 最多 8s）→ 命中则每 250ms 采样 × 40 → 原始采样 postMessage 回 parent → parent 计算守恒漂移与周期估计并出三态角标。未声明约定的页面一律静默（无角标）。
阈值同 M1 拟定值：能量漂移 (max−min)/mean > 2% → fail；声明 model 且估测周期偏差 > 5% → warn。
