# PhyMathia · 物理数学双域解释与可视化助手

> **Phy**sics + **Math**ematics + Utop**ia**
> **让物理有直觉 · 让数学看得见**

PhyMathia 是一个本地部署的 Web 应用：对每一个问题，AI **同时**从「物理直觉」和「数学本质」两条路径给出解释，并且不把回答一丢了事——每次完整回答会在一块**可拖拽、可缩放的探索网画布**上生长成一簇知识节点，你的每一次追问、每一次「没看懂」，都会从对应气泡上长出新分支。学到哪里，网就织到哪里。

画布右下角还住着一个会敲键盘的小助手 **Φ**：既能用自然语言帮你整理知识网络（先预览、后应用、一句话撤销），也能随口回答物理数学小问题。

所有 AI 能力开箱即用——内置免费模型，**无需申请任何 API Key** 即可完整体验；KaTeX / Marked / Mermaid / DOMPurify 全部为本地副本，**零 CDN 依赖**，断网也能渲染。

---

## 核心功能

- **双域解释**：固定六模块输出——核心摘要 → 物理直觉 → 数学本质 → 知识图谱 → 交互可视化 → 延伸思考；公式统一 KaTeX 渲染并自动收进公式速查。
- **探索网画布**：回答簇从中心问题向外生长；追问 / 没看懂 / 进阶学习 / 苏格拉底回答 / 自由续问五种分支；全局搜索、一键自动整理、多画布独立保存、本地与服务端双向同步；整张画布可导出高清 PNG（1×–4×，文字按输出分辨率重排）。
- **交互可视化**：每个回答簇内嵌一个 AI 生成的交互页——拖滑块调参数看曲线实时变化，主题随主应用切换，可全屏、可复制源码。
- **苏格拉底追问**：延伸思考只提问不给答案；「我来回答」后 AI 依你的作答判断理解程度，答对深入、答错换类比重讲，配套错题复习与提示链。
- **Φ 网络助手**：自然语言改图（连线 / 扩展 / 评价）与问答双模式；操作先预览后应用；撤销基于逆操作直接回滚、永远成功；目标歧义时主动反问澄清。
- **会积累的学习系统**：知识点自动入库（知识总览）、公式速查带中文说明、基于你画布内容的知识检测（错题回顾 + 统计）、设备级用户画像（记住学习目标与薄弱点，透明可控可清除）。
- **更多**：难度三档（初高中 / 大学 / 科研）、PDF / Word / PPT / 图片文档上传提取、Φ 桌宠（待机眨眼、工作敲键盘）。

## 快速开始

### 准备

- Python 3.10+（本手册统一写 `python3`；Windows 上若提示找不到命令，改用 `python`）
- 浏览器一个（Chrome / Edge / Firefox 均可）
- Node.js **不需要**——仓库已附带打包好的前端产物，只有改前端源码才需要重新构建（见下文「开发者须知」）

### 安装与启动（两条命令）

```bash
pip install -r requirements.txt
python3 src/main.py
```

启动后浏览器打开 **http://localhost:5050** 即可。想换端口用 `-p`，例如 `python3 src/main.py -p 8080`。

首次启动会自动创建 `data/` 目录存放运行数据（会话、知识库、公式库等），无需手动初始化。

### 建议的第一次体验路线

1. 新建画布，在中央节点输入一个物理问题，比如「什么是简谐运动」；
2. 等回答簇完整长出：摘要、物理、数学、图谱、可视化、延伸思考六个气泡依次点亮；
3. 在「物理直觉」气泡上点「追问」，看新分支从原位长出；
4. 打开可视化模块，拖动滑块亲手调一次频率和振幅；
5. 点右下角的 Φ，输入「围绕简谐运动扩展一条进阶链」，先看操作预览，确认后应用，再说一句「撤销」看它回滚；
6. 打开顶部知识面板，看刚才对话里的知识点和公式已被自动收进总览与公式速查。

### 验证部署

```bash
curl http://localhost:5050/health        # 返回 {"status":"ok",...} 即服务正常
```

开发者可另跑自动化测试确认环境完整：

```bash
python3 -m pytest tests/ -q              # 后端单测，应全部通过（基线数字见 AGENTS.md）
node scripts/frontend_smoke.mjs          # 前端冒烟 90 条 ✓（需要 npm install 先装依赖）
```

## 项目结构

| 目录 | 内容 |
|---|---|
| `src/main.py` | 入口：一条命令启动整个服务 |
| `src/server/` | 后端模块（知识提取、知识大陆、用户画像、模型路由等） |
| `harness/` | Φ 助手后端（改图评审、撤销、澄清、流式），挂载在 `/api/harness` |
| `src/static/js/` | 前端源码模块；`app.js` / `viewer.js` 是打包产物 |
| `src/static/vendor/` | KaTeX、Marked、Mermaid、DOMPurify 本地副本（零 CDN） |
| `data/` | 运行时 JSON 数据，服务首次启动自动创建 |
| `scripts/` | 前端构建与测试脚本 |
| `tests/` | 后端单测 |
| `docs/` | 手册、开发日志、参赛材料（见下方文档地图） |
| `html/` | 参赛演示物料（海报 / 演示回放，独立 git 仓库） |

## 技术栈

- **后端**：Python + FastAPI + Uvicorn，回答流式输出，本地 JSON 存储
- **前端**：原生 JavaScript，esbuild 打包为单文件 `app.js`；可视化画布为 Canvas 渲染，交互页跑在沙箱 iframe 里
- **AI 接入**：内置免费模型开箱即用，也可在应用内的模型设置中配置自己的模型槽位

## 开发者须知

- **改后端代码**（`src/main.py`、`src/server/`、`harness/`、`src/system prompt.md`）后需重启服务生效；服务默认不带热重载。
- **改前端源码**（`src/static/js/*.js`、CSS、`/phi/phi-pet.*`）后必须执行 `npm install && npm run build:js` 重新打包再刷新页面；只改查看器相关（`viewer-*.js`）另跑 `npm run build:viewer`。
- **动手改代码前先读 [`AGENTS.md`](AGENTS.md)**——里面有每个会话都适用的硬规则，以及「改哪块先读哪本手册」的模块地图。
