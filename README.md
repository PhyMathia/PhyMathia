# PhyMathia · 物理数学双域解释与可视化助手

> **Phy**sics + **Math**ematics + Utop**ia**
> **让物理有直觉 · 让数学看得见**

PhyMathia 是一个本地部署的 Web 应用：对每一个问题，AI **同时**从「物理直觉」和「数学本质」两条路径给出解释，并且不把回答一丢了事——每次完整回答会在一块**可拖拽、可缩放的探索网画布**上生长成一簇知识节点，你的每一次追问、每一次「没看懂」，都会从对应气泡上长出新分支。学到哪里，网就织到哪里；学过的知识还会跨会话沉淀到一张「知识大陆」上，长成你自己的知识地图。

画布右下角还住着一个会敲键盘的小助手 **Φ**：既能用自然语言帮你整理知识网络（先预览、后应用、一句话撤销），也能随口回答物理数学小问题，还能帮你「发明」新类型的知识节点。

所有 AI 能力开箱即用——内置免费模型，**无需申请任何 API Key** 即可完整体验；KaTeX / Marked / Mermaid / DOMPurify 全部为本地副本，**零 CDN 依赖**，断网也能渲染。

## 核心功能

### 双域解释：一个问题，两条路径

每次提问，AI 按固定结构输出一整簇内容，而不是一段格式随机的聊天：

| 模块 | 内容 |
|---|---|
| 核心摘要 | 先给结论 |
| 物理直觉 | 日常类比、因果链推演、跨领域类比、反直觉揭示 |
| 数学本质 | 从现象到方程的完整推导，逐项解释符号含义与适用范围 |
| 知识图谱 | 概念关系图，至少 3 个上游 + 3 个下游——看见概念站在知识的哪个位置 |
| 交互可视化 | AI 生成的沙箱内嵌交互页（见下） |
| 苏格拉底追问 | 让 AI 陪你思考 |
| 进阶学习 | AI 提供 3 个进阶方向 |

所有公式统一 KaTeX 渲染，并自动收进公式速查。

### 探索网画布：知识不是聊天记录，是一张网

- 回答簇从中心问题向外生长；**追问 / 没看懂 / 进阶学习 / 苏格拉底回答 / 自由续问**五种分支——从哪个气泡发起，新节点就长在哪里；
- 双击空白创建自定义节点（我的理解、输入、文档……），全局搜索当前或全部画布，一键自动整理；
- 多画布独立保存，本地与服务端自动双向同步；
- 一键导出高清 PNG 知识海报：1×–4× 四档倍数 + 透明背景可选，文字按输出分辨率重新排版而非放大位图，任意倍数下字迹都清晰；
- 大画布也流畅：节点按视口分档渲染，DOM 数量减少 83%，最长卡顿 2121ms → 343ms（实测）。

### 知识大陆：跨会话生长的知识地图

学过的知识点会自动投影到一张可缩放的「大陆」上——概念卡、岛、海域、城市、航线分层呈现；拉远看知识亲缘，推近无缝落回具体画布。内置本地向量模型做语义「找亲」：新知识点自动判断落在哪座岛，搜「电磁感应」也能找到只写了「法拉第」的节点。触屏双指缩放、键盘操作、搜索、加载态一应俱全。

### 交互可视化：亲手摸到每个变量

每个回答簇内嵌一个 AI 生成的交互页：拖动滑块调参数，看曲线实时变化；折线图、热力图、3D 透视图、可暂停可调速的动画，按概念特点智能选择。主题随主应用切换，可全屏、可复制源码，全部运行在安全沙箱 iframe 里。

### 苏格拉底追问：AI 不替你思考，陪你思考

延伸思考只提问、不给答案（基础 / 进阶 / 拓展三档）。点「我来回答」，AI 依你的作答判断理解程度——答对继续深入，答错换一种类比重讲。配套完整的练习机制：错题自动进入复习队列、答题前把握度自评、答不上来有提示链出口而不是直接摊牌。

### Φ 网络助手：改图、答疑、创造三种模式

右下角的 Φ 既能动手，也能开口：

- **改图**：「围绕简谐运动扩展一条进阶链」「整体评价一下这张图」——提取知识点、建立/修正连线、扩展、生成评价，全部先预览、经你确认才应用；目标歧义时它会主动反问，而不是猜一个答案硬做；
- **答疑**：物理数学小问题随口就问；回答前先检索你的知识库与画布（字面 + 本地向量语义双路），引用你学过的内容作答；
- **创造**：用自然语言「发明」新类型的知识节点——提需求、预览、应用到画布全链路，可存为配方反复使用；
- **学习体检**：问「先学什么」「这张学习网络合不合理」，Φ 先对整张图做结构统计（孤岛主题、知识链深、薄弱点覆盖），再给出一份学习路线报告；
- **确定性撤销**：撤销基于逆操作直接回滚、不调模型——撤销永远成功；「全部撤销」一键回到最初；每次改图都有事件日志，可任意步回退；失败自动重试、可一键换模型。

### 会积累的学习系统

- **知识总览**：对话中的知识点自动提取入库，分类、搜索、收藏，点击跳回来源画布并高亮原位置；
- **公式速查**：自动收集对话中的公式，标准化去重，每条附中文说明；
- **知识检测**：基于你画布里的知识点和公式出选择题，按掌握度与错题自适应出题（薄弱点优先），AI 盲答校验题目质量；错题回顾 + 全局统计——检测不是打分，是照见「以为懂了、其实没懂」的地方；
- **行为画像**：用户画像从日常使用中顺带记住你的学习目标与薄弱点（多次出现才固化，单次先进建议区等你确认），驱动自适应出题与举例方向；面板里一切透明可控、可清除；
- **多账号**：学习数据按账号隔离，各自的画布、知识库、检测记录与画像互不混淆。

### 导出、分享与个性化

- **.pmu 快照与外发**：自有快照格式——会话记录查看、直传预览、拖回主应用恢复、单文件网页外发；外发页默认只读，防止接收方误改；
- **主题体系**：五套面板风格（极光 / 蓝图 / 砚石 / 霓虹 / 糖果）× 节点皮肤 × 壁纸自由组合，深浅色成对适配，桌宠与导出跟随主题；
- **更多**：难度三档（初高中 / 大学 / 科研）、PDF / Word / PPT / 图片文档上传提取知识点、任务列表面板、新手步骤引导、数据一键导出/导入/存储诊断。

## 快速开始

### 准备

- Python 3.10+（本手册统一写 `python3`；Windows 上改用 `python`）
- 浏览器一个（Chrome / Edge / Firefox 均可）
- Node.js **不需要**——仓库已附带打包好的前端产物，只有改前端源码才需要重新构建（见下文「开发者须知」）

### 安装与启动

**方式一：一键启动（推荐新手）**

- **Windows**：双击 `start.bat`；
- **Linux / macOS**：终端里运行 `./start.sh`（提示没权限就改用 `bash start.sh`）。

首次运行会自动创建虚拟环境并安装依赖（需要联网，可能要几分钟），之后每次都是点开即用；服务就绪后会自动帮你打开浏览器，**关闭窗口或按 Ctrl+C 即停止服务**。

**方式二：手动启动（两条命令）**

```bash
pip install -r requirements.txt
python3 src/main.py
```

启动后浏览器打开 **http://localhost:5050** 即可。想换端口用 `-p`，例如 `python3 src/main.py -p 8080`；一键启动换端口用 `PHYMATHIA_PORT=8080 ./start.sh`（Linux / macOS）。

首次启动会自动创建 `data/` 目录存放运行数据（会话、知识库、公式库等），无需手动初始化。

### 建议的第一次体验路线

1. 新建画布，在中央节点输入一个物理问题，比如「什么是简谐运动」；
2. 等回答簇完整长出：摘要、物理、数学、图谱、可视化、延伸思考六个气泡依次点亮；
3. 在「物理直觉」气泡上点「追问」，看新分支从原位长出；
4. 打开可视化模块，拖动滑块亲手调一次频率和振幅；
5. 点右下角的 Φ，输入「围绕简谐运动扩展一条进阶链」，先看操作预览，确认后应用，再说一句「撤销」看它回滚；
6. 打开顶部知识面板，看刚才对话里的知识点和公式已被自动收进总览与公式速查；
7. 打开「知识大陆」，看刚才学到的知识已经落在哪座岛上。

### 验证部署

```bash
curl http://localhost:5050/health        # 返回 {"status":"ok",...} 即服务正常
```

开发者可另跑自动化测试确认环境完整：

```bash
python3 -m pytest tests/ -q              # 后端单测，应全部通过（基线数字见 AGENTS.md）
node scripts/frontend_smoke.mjs          # 前端冒烟 310 条 ✓（需要 npm install 先装依赖）
```

## 项目结构

| 目录 | 内容 |
|---|---|
| `src/main.py` | 入口：一条命令启动整个服务 |
| `src/server/` | 后端模块（知识提取、知识大陆、用户画像、模型路由等） |
| `harness/` | Φ 助手后端（改图评审、撤销、澄清、流式），挂载在 `/api/harness` |
| `src/static/js/` | 前端源码模块；`app.js` / `viewer.js` 是打包产物 |
| `src/static/vendor/` | KaTeX、Marked、Mermaid、DOMPurify 本地副本（零 CDN） |
| `data/` | 运行时 JSON 数据，服务首次启动自动创建 |
| `scripts/` | 前端构建与测试脚本 |
| `tests/` | 后端单测 |

## 技术栈

- **后端**：Python + FastAPI + Uvicorn，回答流式输出，本地 JSON 存储，零数据库依赖
- **前端**：原生 JavaScript，esbuild 打包为单文件 `app.js`；可视化画布为 Canvas 渲染，交互页跑在沙箱 iframe 里
- **上下文按图构建**：当前分支只继承所在路径——上游给摘要、当前给全文、兄弟分支不串线；长会话后台异步摘要滚动记忆
- **AI 接入**：可在应用内的模型设置中配置自己的模型槽位；可选择内置本地向量模型做语义检索，离线自动降级为字面匹配

## 开发者须知

- **改后端代码**（`src/main.py`、`src/server/`、`harness/`、`src/system prompt.md`）后需重启服务生效；服务默认不带热重载。
- **改前端源码**（`src/static/js/*.js`、CSS、`/phi/phi-pet.*`）后必须执行 `npm install && npm run build:js` 重新打包再刷新页面；只改查看器相关（`viewer-*.js`）另跑 `npm run build:viewer`。
- **动手改代码前先读 [`AGENTS.md`](AGENTS.md)**——里面有每个会话都适用的硬规则，以及「改哪块先读哪本手册」的模块地图。

## 为什么做 PhyMathia

起点是英语课上一次失败的演讲——「行列式的几何意义」，准备了很多，却没有讲透。真正让我难受的不是演讲效果，而是我发现：很多同学对这个话题根本不感兴趣，甚至厌恶思考。难道学习就是对着教科书背干条条、听网课总结做题套路、从早刷题到晚、考完立刻清空大脑？如果是这样，考到高分又怎样。

所以有了 PhyMathia。**Phy**sics + **Math**ematics + Utop**ia**：「双域」是物理和数学两个领域——物理给出直觉与意义，数学给出结构与精度；而 Utopia 不是指一个完美的产品，是指一种**理想的学习状态**。我把它放进名字里，提醒自己为什么要做这件事。

我相信：

- **学科本来就是一张网。** 学科边界是为了方便研究而建立的**分类**，不是自然规律本身的边界。所以学习不该只是不断增加知识点数量，而该不断寻找知识背后的**共同结构**。
- **知其然，更要知其所以然。** 记忆永远追不上知识的增长，但理解可以迁移。
- **可视化是加深理解最有效的手段之一。** 理解，常常发生在看见变化的那一瞬间。
- **AI 不替你思考，陪你思考。**
- **因为热爱探索，所以探索。** 当外在目的完全取代内在动力，学习就不再是认识世界，而变成了一场交换。

每个功能背后都有一个关于学习的主张：

| 功能 | 它表达的主张 |
|---|---|
| 双域解释 | 让物理与数学互相照亮，而不是各讲各的 |
| 探索网画布 | 知识不是一串聊天气泡，而是一张网——把「知识之间有关系」直接画出来 |
| 知识图谱 | 看见一个概念站在知识网络的哪个位置 |
| 苏格拉底追问 | 只提问、不给答案——AI 陪你思考，不替你思考 |
| 知识检测 | 检测不是打分，是发现「以为懂了、其实没懂」的地方 |
| 公式速查 | 公式不该背，该随时可查、可重新理解 |




我不认为我找到了最终答案，也不认为 PhyMathia 能解决教育中的所有问题。它只是我的一个理想、一次尝试。但如果没有人尝试，这种想法永远只会是想法。
